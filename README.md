# Sujitha Gurumoorthy — Premium AI/ML Engineer Portfolio & Dashboard

A personalized, accessible portfolio dashboard engineered with **React**, **Vite**, and **Tailwind CSS**. Designed specifically around Sujitha Gurumoorthy's academic background at Sir Issac Newton College of Engineering and Technology, hands-on AI projects, verified certifications, industry community exposure (Google & NVIDIA ecosystems), and career roadmap toward becoming a Machine Learning Engineer.

---

## 🌟 Visual Identity & Design Highlights

- **Aesthetic Color Palette**: Refined Deep Navy (`#0A0F1D`, `#0F182E`, `#14213D`), soft lavender (`#FAF8FF`, `#F4F0FF`, `#E7DCFE`), and subtle sky/blue accents (`#38BDF8`, `#2563EB`).
- **Dark Mode & Light Mode**: Smooth theme transitions between crisp white/lavender and rich deep navy with subtle glowing borders.
- **Scroll-Reveal & Hover Animations**: Smooth viewport reveal animations, card hover lift effects, skill badge scale interactions, and button hover states—all respecting `@media (prefers-reduced-motion: reduce)`.
- **Dynamic Metrics Dashboard**: Real-time totals computed directly from portfolio state.
- **In-Browser Portfolio Studio (Admin Mode)**: Update profile details, upload photos, manage projects, and export/import JSON backups locally in the browser without rewriting code.

## 🚀 Quick Start (Run Locally)

### 1. Install Dependencies (if not already installed)
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```

Navigate to:
```
http://localhost:5173
```

### 3. Build for Production
```bash
npm run build
```
